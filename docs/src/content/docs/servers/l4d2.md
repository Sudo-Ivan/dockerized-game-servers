Compose path: l4d2. Image: l4d2.

## Behavior

Downloads the Linux dedicated server (Steam App 222860) on first start. Data volume: `l4d2/data` mounted at `/opt/l4d2`.

SteamCMD no longer serves this app to anonymous login. Use `STEAM_USERNAME` and `STEAM_PASSWORD` for an account that owns Left 4 Dead 2. Optional `STEAM_GUARD_CODE` for Steam Guard.

- Game: TCP and UDP 27015, UDP 27005
- Default map: `c1m1_hotel` (`L4D2_STARTMAP`)
- Updates: `L4D2_FORCE_UPDATE=true` or `./tools/gs update l4d2`

## Compose

```bash
export STEAM_USERNAME=youruser
export STEAM_PASSWORD=yourpass
docker compose -f l4d2/docker-compose.yml up -d
```

## Docker run

```bash
docker run -d --name l4d2 --restart unless-stopped --init \
  -p 27015:27015/tcp -p 27015:27015/udp -p 27005:27005/udp \
  -v "$PWD/l4d2/data:/opt/l4d2" \
  {{IMAGE_PREFIX}}/l4d2:latest
```
