---
title: Left 4 Dead 2
description: Left 4 Dead 2 dedicated server via SteamCMD, App 222860.
---

On first start the container downloads the Left 4 Dead 2 dedicated server through Steam, then launches it as a native Linux server (no Wine).

:::note[Before you start]
- Open TCP port 27015, UDP port 27015, and UDP port 27005
- Keep a data folder mounted at /opt/l4d2 inside the container
- Anonymous Steam login often fails for this game. Set STEAM_USERNAME and STEAM_PASSWORD for an account that owns Left 4 Dead 2. Add STEAM_GUARD_CODE if Steam asks for it
:::

## Ports

| Port | Protocol | Purpose |
| --- | --- | --- |
| 27015 | TCP | Game port. Also used for remote console once you set rcon_password in server.cfg or through L4D2_EXTRA_ARGS |
| 27015 | UDP | Main game port (L4D2_PORT) |
| 27005 | UDP | Client port (Source engine default) |

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| STEAM_USERNAME | anonymous | Steam account used to download server files |
| STEAM_PASSWORD | (empty) | Password for STEAM_USERNAME when not using anonymous login |
| STEAM_GUARD_CODE | (empty) | One-time Steam Guard dockerized/code if Steam challenges the login |
| L4D2_APP_ID | 222860 | Steam app id for the dedicated server download |
| L4D2_FORCE_UPDATE | false | Re-download and validate server files on next start |
| STEAMCMD_WINDOWS_WORKAROUND | full | How SteamCMD fetches depots. full downloads a Windows pass first, then Linux. prime and off are lighter options |
| L4D2_PORT | 27015 | Game port |
| L4D2_MAXPLAYERS | 8 | Maximum players |
| L4D2_STARTMAP | c1m1_hotel | Map loaded at startup |
| L4D2_TICKRATE | 30 | Server tickrate |
| L4D2_EXTRA_ARGS | (empty) | Extra launch flags appended after the built-in ones |

The server always starts with the Left 4 Dead 2 game mode, console access, remote console support, and strict port binding.

## Data folder

Your data folder mounts to /opt/l4d2 inside the container.

| Path | Purpose |
| --- | --- |
| srcds_run | Server launcher installed by Steam |
| steam_appid.txt | Written on every start with app id 550 for Steamworks |
| left4dead2/cfg/server.cfg | Main server config. Create this yourself |
| left4dead2/maps/ | Custom or workshop maps |
| left4dead2/addons/ | SourceMod or Metamod if you add plugins |

## Updates

Set L4D2_FORCE_UPDATE to true and recreate the container, or use the update workflow in [Ops](/guides/ops/).

## Health check

The container reports healthy while the game server process is running. The first Steam download can take a while, so startup gets a 600 second grace period.

## Notes

- The container starts as root, fixes ownership of the data folder, then runs the server as the dockerized/l4d2 user (uid 1000).
- There is no dedicated remote console setting. TCP port 27015 handles remote console once you set rcon_password in server.cfg.
- Strict port binding is always on. If L4D2_PORT is already in use, the server exits instead of picking another port. Check docker logs l4d2 if the container stops right away.
- With STEAMCMD_WINDOWS_WORKAROUND at its default of full, the first download runs twice (Windows depot pass, then Linux). The first docker compose up takes longer than later updates.
- Compose sets a 2 GB memory limit and a 90 second stop grace period. The image sends SIGINT on stop so the server can shut down cleanly.

## Compose

```bash
export STEAM_USERNAME=youruser
export STEAM_PASSWORD=yourpass
docker compose -f dockerized/l4d2/docker-compose.yml up -d
```

## Docker run

```bash
docker run -d --name l4d2 --restart unless-stopped --init \
  -p 27015:27015/tcp -p 27015:27015/udp -p 27005:27005/udp \
  -v "$PWD/dockerized/l4d2/data:/opt/l4d2" \
  -e STEAM_USERNAME="your_steam_user" \
  -e STEAM_PASSWORD="your_steam_password" \
  -e L4D2_STARTMAP=c1m1_hotel \
  {{IMAGE_PREFIX}}/l4d2:latest
```
