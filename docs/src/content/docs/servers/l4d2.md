Compose path: l4d2. Image: l4d2.

Left 4 Dead 2 dedicated server built on the shared [steam-base](/reference/images/) image. SteamCMD installs App **222860** (the Linux dedicated server depot) and the entrypoint launches `srcds_run` directly, no Wine involved.

:::note[Requirements]
- Publish TCP **27015**, UDP **27015**, and UDP **27005**
- Persist `./data` at `/opt/l4d2`
- Anonymous SteamCMD login frequently fails for App 222860, set `STEAM_USERNAME` and `STEAM_PASSWORD` for an account that owns Left 4 Dead 2, optional `STEAM_GUARD_CODE` if Steam Guard prompts for a code
:::

## Ports

| Port | Protocol | Purpose |
| --- | --- | --- |
| 27015 | TCP | Same game port, doubles as the RCON channel once `rcon_password` is set in `server.cfg` or via `L4D2_EXTRA_ARGS` |
| 27015 | UDP | Main game port (`L4D2_PORT`), also passed as `+hostport` |
| 27005 | UDP | Client port, Source engine default, not read from any env var here |

## Environment

| Variable | Default | Purpose |
| --- | --- | --- |
| `STEAM_USERNAME` | `anonymous` | Steam login for the SteamCMD install step |
| `STEAM_PASSWORD` | (empty) | Password for `STEAM_USERNAME`, required for non-anonymous login |
| `STEAM_GUARD_CODE` | (empty) | Steam Guard code, only needed if Steam challenges the login |
| `L4D2_APP_ID` | `222860` | SteamCMD app id for the dedicated server depot |
| `L4D2_FORCE_UPDATE` | `false` | Set `true` to force `app_update 222860 validate` on next start |
| `STEAMCMD_WINDOWS_WORKAROUND` | `full` | SteamCMD depot fetch mode (`full`, `prime`, or `off`), `full` pulls a Windows depot pass before the Linux depot |
| `L4D2_PORT` | `27015` | Game port, passed as `+port` and `+hostport` |
| `L4D2_MAXPLAYERS` | `8` | Player cap, passed as `+maxplayers` |
| `L4D2_STARTMAP` | `c1m1_hotel` | Map loaded on startup, passed as `+map` |
| `L4D2_TICKRATE` | `30` | Server tickrate, passed as `-tickrate` |
| `L4D2_EXTRA_ARGS` | (empty) | Extra `srcds_run` arguments, space separated, appended after the built-in flags |

The entrypoint always passes `-game left4dead2`, `-console`, `-usercon`, and `-strictportbind`.

## Data volume

`./data` mounts to `/opt/l4d2`.

| Path | Purpose |
| --- | --- |
| `srcds_run` | Server launcher, installed by SteamCMD |
| `steam_appid.txt` | Rewritten on every start with `550`, the Steamworks app id L4D2 needs at runtime |
| `left4dead2/cfg/server.cfg` | Main server config, create it yourself, the entrypoint does not generate one |
| `left4dead2/maps/` | Custom or workshop maps you copy in manually |
| `left4dead2/addons/` | SourceMod or Metamod install location if you add server plugins |

## Updates and healthchecks

Set `L4D2_FORCE_UPDATE=true` or run `./tools/gs update l4d2` from the [Ops](../guides/ops/) guide. The healthcheck is a `process` probe (`pgrep -f srcds_linux`) with a 600 second start period, since the first SteamCMD install can take a while.

## Notes

- The l4d2 image has no Dockerfile `USER`, so the container starts as root. `docker-entrypoint.sh` creates and chowns `/opt/l4d2` and `/home/l4d2` to the `l4d2` user (uid 1000) on every start, then re-execs `entrypoint.sh` under that user with `runuser`.
- There is no dedicated RCON environment variable. TCP 27015 is the RCON channel once you set `rcon_password` yourself, and `-usercon` is always passed to open the engine's console socket.
- `-strictportbind` is always passed, so the server exits immediately rather than silently rebinding if `L4D2_PORT` is already taken, check `docker logs l4d2` before assuming a hang.
- First install downloads twice (a Windows depot pass, then the Linux depot) because `STEAMCMD_WINDOWS_WORKAROUND` defaults to `full`. Expect the first `docker compose up` to take longer than a later `L4D2_FORCE_UPDATE` run.
- Compose sets `mem_limit: 2048M` and `stop_grace_period: 90s`, the image sends `SIGINT` on stop so `srcds` can shut down cleanly.

## Compose

```bash
export STEAM_USERNAME=youruser
export STEAM_PASSWORD=yourpass
docker compose -f l4d2/docker-compose.yml up -d
```

## Docker run

```bash
docker run -d --name l4d2 --restart unless-stopped --init \
  -p 27015:27015/tcp -p 27015:27015/udp -p 27005:27005/udp \
  -v "$PWD/l4d2/data:/opt/l4d2" \
  -e STEAM_USERNAME="your_steam_user" \
  -e STEAM_PASSWORD="your_steam_password" \
  -e L4D2_STARTMAP=c1m1_hotel \
  {{IMAGE_PREFIX}}/l4d2:latest
```
