title: Battlefield 1942
description: Battlefield 1942 dedicated server (LinuxGSM bundle).
---

Compose path: `bf1942`. Image: `bf1942`.

Linux dedicated files are seeded from the image into `bf1942/data` on first start. You must comply with EA licensing for Battlefield 1942 when operating a public server.

## Ports

- UDP **14567** (game)
- UDP **23000** (query)

## Configuration

| Variable | Purpose |
| --- | --- |
| `BF1942_EXTRA_ARGS` | Extra `+` arguments appended to the server command line |

## Compose

```bash
docker compose -f bf1942/docker-compose.yml up -d
```

## Docker run

```bash
docker run -d --name bf1942 --restart unless-stopped --init \
  -p 14567:14567/udp -p 23000:23000/udp \
  -v "$PWD/bf1942/data:/opt/bf1942" \
  {{IMAGE_PREFIX}}/bf1942:latest
```
