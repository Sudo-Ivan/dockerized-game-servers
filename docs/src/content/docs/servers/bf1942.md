This image ships with the game server files built in. On first run they are copied into your data folder. You must own Battlefield 1942.

:::note[Before you start]
- You must own Battlefield 1942
- Keep a data folder for the server install, mods, and any config you edit
- Open UDP port 14567 and TCP port 23000
:::

## Ports

| Port | Protocol | Purpose |
| --- | --- | --- |
| 14567 | UDP | Game traffic (fixed, no setting to change it) |
| 23000 | TCP | Status and query port used by the bundled status daemon (fixed) |

Neither port can be changed with an environment variable. Both come from the bundled start script defaults.

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| BF1942_EXTRA_ARGS | (empty) | Extra flags appended to the start command |

This is the only setting the container reads. There are no hostname, map, or player-count options. Everything else comes from config files inside the data folder or from flags you add through BF1942_EXTRA_ARGS.

## Data folder

Your data folder mounts to /opt/bf1942 inside the container. On first start (or if key files are missing), the container copies the built-in server files into that folder and marks the copy as complete. After that it leaves the folder alone.

The copied tree includes the game binary, start scripts, a status daemon, and map archives. There is no generated server.cfg. Hostname, map rotation, player count, and rcon all live in config files under mods/bf1942/. Edit them on the host with the container stopped.

Do not delete the completion marker or game binary unless you want to wipe your config changes and start from the built-in copy again.

## Updates

There is no one-command update for this server. Use [backup and restore](../guides/ops/) to protect your data. To pick up a newer game archive, change the build settings in the Dockerfile and rebuild the image.

## Health check

The container reports healthy while the game server process is running. Startup gets a 180 second grace period.

## Compose

```bash
docker compose -f bf1942/docker-compose.yml up -d
```

## Docker run

```bash
docker run -d --name bf1942 --restart unless-stopped --init \
  -p 14567:14567/udp -p 23000:23000/tcp \
  -v "$PWD/bf1942/data:/opt/bf1942" \
  -e BF1942_EXTRA_ARGS="" \
  {{IMAGE_PREFIX}}/bf1942:latest
```
