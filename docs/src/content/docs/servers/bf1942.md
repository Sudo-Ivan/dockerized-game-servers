Compose path: bf1942. Image: bf1942.

Server files are baked from the same [LinuxGSM download](http://linuxgsm.download/BattleField1942/) archive used upstream. You must own Battlefield 1942. On first start the image copies the seed into `bf1942/data` (`/opt/bf1942`).

## Ports and volume

- UDP 14567 (game)
- TCP 23000 (status)
- Data: `bf1942/data` at `/opt/bf1942`
- Extra console args: `BF1942_EXTRA_ARGS`

## Docker run

```bash
docker run -d --name bf1942 --restart unless-stopped --init \
  -p 14567:14567/udp -p 23000:23000/tcp \
  -v "$PWD/bf1942/data:/opt/bf1942" \
  {{IMAGE_PREFIX}}/bf1942:latest
```
