# Tools

Interactive generators that build config files and podman commands for the servers in this repository. Everything runs client-side in your browser. Nothing you type is uploaded or stored anywhere.

| Tool | Produces |
| --- | --- |
| [Arma 3 config generator](arma-3-config-generator.md) | server.cfg for the [Arma 3](../servers/arma-3.md) image |
| [Minecraft server.properties generator](minecraft-server-properties-generator.md) | server.properties for the [Minecraft](../servers/minecraft.md) images |
| [Podman run and compose generator](podman-run-generator.md) | podman run commands and compose.yml snippets for any server |

!!! note "Client-side only"

    Forms on these pages render output in your browser with plain JavaScript. Reloading the page resets the form.

## Requesting a tool

Open an issue on [GitHub]({{GITHUB_URL}}/issues) if a generator for another server would help.
